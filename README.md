# School Bus Tracking

Two apps live in this repo as separate code sections:

| Folder    | App                        | Status        |
|-----------|----------------------------|---------------|
| `child/`  | **Beacon Go** (child app)  | Tracker screen UI |
| `parent/` | **Beacon** (parent app)    | Coming next   |

## Run the child app

It is plain HTML, CSS and JavaScript with no build step. Open `child/index.html` in a browser, or serve the folder:

```sh
npx serve child
```
